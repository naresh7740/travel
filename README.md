# Jagdish Tour And Travels

A lightweight static travel website built with HTML, CSS, and JavaScript. It has no package installation or build step.

## Project structure

```text
.
├── index.html
├── about.html
├── contact-details.html
├── gallery.html
├── destinations/
│   └── *.html
├── css/
│   ├── about.css
│   ├── booking.css
│   ├── contact-details.css
│   ├── destinations.css
│   ├── gallery.css
│   ├── home.css
│   ├── language-switcher.css
│   └── location-map.css
├── js/
│   ├── booking-whatsapp.js
│   ├── destination-preview.js
│   ├── language-switcher.js
│   └── navigation.js
├── assets/
│   ├── vehicles/
│   └── images, logo, and contact resources
└── docs/
    └── Jagdish_Tour_and_Travels_Website_Content.md
```

## Deploy

Publish the project root as the static site root—the folder containing `index.html`. Include the `css/`, `js/`, `assets/`, and `destinations/` folders. No build command is required.
